## Limits, in the vendor's words

Mistral states the offer in one sentence and publishes no figure for it: "Free mode lets you create API keys and use included monthly usage within the limits shown on the Limits page". The limits it describes are per model — tokens per minute, requests per second, audio seconds per month — and are shown only inside an account, and paid use is documented as an extension of the same plan rather than a second one ("It is not a separate plan for the API"). The page names no model, which is why the Free models column here is empty (read 2026-08-14)
