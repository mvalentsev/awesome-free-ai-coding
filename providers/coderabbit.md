## What you get

Code reviews for local Git changes through an installed CLI or VS Code extension, with an ongoing Free plan alongside a separate introductory trial

## Free models

The vendor does not identify which models the free offer includes. See Limits for the published conditions.

## Limits, in the vendor's words

Free CLI reviews: 3 reviews/rolling hour per person

Free IDE reviews: 3 reviews/rolling hour per person

Sign-in is required. New organizations start with a separate "14-day Advanced trial". Free PR access provides summaries; open-source PR reviews have a separate allowance. Proprietary code is not used for model training, but open-source code may train the service. Review-personalization data is stored unless you opt out of storage.

## Where it is offered

The vendor names no country it keeps the offer from ([source](https://www.coderabbit.ai/terms-of-service), read 2026-10-31).

## What happens to what you send

What you send may be used to train or improve models. In the vendor's words: “The above representation does not apply to open-source projects (OSS). We use OSS to train our systems.” ([source](https://www.coderabbit.ai/privacy-policy)).
